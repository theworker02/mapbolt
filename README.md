# mapbolt

Map URLs and bolt query parts with stable normalization.

**Site:** https://theworker02.github.io/mapbolt/

## Install / run

```bash
git clone https://github.com/theworker02/mapbolt.git
cd mapbolt
node src/cli.js
node --test
```
